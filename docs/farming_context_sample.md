# Farming Knowledge Context (Sample)

Use this file as optional background context for farm-planning questions.
It is intentionally practical and small so it can fit within prompt budgets.

## Farm Profile

- Size: 5 acres total
- Climate: warm temperate, rainy spring, dry late summer
- Soil baseline: low organic matter (about 2.1%), moderate compaction in wheel tracks
- Water source: one pond + drip irrigation on main vegetable blocks
- Labor: 3 full-time equivalent workers in peak season

## Production Goals

- Increase soil organic matter over 3 years
- Reduce purchased synthetic inputs
- Keep cashflow stable through diversified harvest windows
- Improve drought resilience without major capex

## Current Crops

- Block A: tomatoes, peppers
- Block B: lettuce, brassicas
- Block C: squash, cucumbers
- Block D: mixed cover crop (winter only)
- Block E: wash/pack + nursery + access lanes

## Operating Constraints

- No-till transition must be gradual
- One tractor, limited implement changes per week
- Compost supply is limited and costly to truck in
- Must preserve at least 60% of normal market volume during transition

## Heuristics / Best Practices

1. Rotation: avoid planting the same family in the same block in consecutive seasons.
2. Cover crops: prioritize diverse mixes (grass + legume + brassica) when windows allow.
3. Soil cover: keep living roots or residue on beds as many days per year as possible.
4. Water efficiency: drip + mulch beats overhead irrigation for disease-sensitive crops.
5. Pest pressure: use trap crops and beneficial habitat strips at block edges.
6. Nutrient strategy: compost for structure/biology, targeted amendments for deficiencies.
7. Risk management: stagger planting dates to avoid single weather-event losses.

## Decision Preferences

- Prefer low-regret, stepwise changes over full-system resets
- Favor interventions with measurable indicators inside one season
- Include tradeoffs and uncertainty explicitly

## Metrics To Track

- Soil organic matter %
- Infiltration rate
- Yield per block
- Input cost per bed-foot
- Irrigation water use
- Culls / disease incidence

## Output Style Preference

When answering farm-planning questions, provide:

- A phased plan (0-3 months, 3-12 months, 1-3 years)
- Expected upside, operational risk, and labor impact for each phase
- A minimal KPI dashboard (3-5 metrics) with target ranges
